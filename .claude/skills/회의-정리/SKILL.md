# 회의-정리

회의 메모 또는 전사록을 아래 형식으로 정리한다.

## 입력

- 사용자가 대화에 붙여 넣은 회의 메모 또는 전사록
- 또는 사용자가 지정한 파일 경로 (예: `가상회의_전사록.txt`). 파일을 읽은 뒤 정리한다.
- 입력이 비어 있거나 플레이스홀더만 있으면 정리하지 말고, 메모를 붙여 달라고 한 줄로 요청한다.

## 출력 형식

아래 순서와 제목을 그대로 사용한다.

1. **맨 위 한 줄 요약**: 회의의 핵심 결론을 한 문장으로. 결정 사항과 다음 단계가 함께 드러나게 쓴다.
2. **결정된 것**: 합의되어 확정된 사항을 항목별로. 근거나 조건이 있으면 함께 적는다.
3. **누가, 언제까지, 무엇을**: 표로 작성한다. 열은 `담당 | 기한 | 할 일` 순서.
   - 담당자와 기한이 메모에 없으면 빈칸으로 두고 `(미지정)`이라고 표시한다. 임의로 채우지 않는다.
   - 기한은 `MM/DD (요일)` 형식으로 쓴다. 날짜 연도가 없으면 회의 날짜 기준으로 맞춘다.
4. **아직 안 정해진 것**: 논의만 되고 결론이 없는 사항, 기준 수치가 없는 사항, 결과를 기다리는 사항을 항목별로.

## 규칙

- 메모에 없는 내용을 추가하지 않는다. 추정이 필요하면 "추정"이라고 표시한다.
- 한 항목이 결정인지 미정인지 애매하면 "아직 안 정해진 것"에 넣는다.
- 액션 아이템은 한 사람에 하나씩 나누어 적는다. 여러 사람이 맡은 일은 사람별로 행을 나눈다.
- 회의 참석자 이름과 메모의 표현은 그대로 쓴다.
- 파일로 저장하라는 요청이 있을 때만 `.txt` 파일로 저장한다. 기본 출력은 채팅 응답이다.

## 저장 (요청 시)

- 사용자가 저장을 원하면 같은 내용을 `.txt`로 저장한다. 파일명은 `회의정리_<회의 날짜>.txt` 형식을 기본으로 하고, 사용자가 지정한 이름이 있으면 그 이름을 따른다.
- 저장 위치는 사용자가 지정하지 않으면 작업 디렉터리 루트로 한다.
- 커밋과 푸시는 사용자가 요청할 때만 한다.
